# Assets for IPTV App

## PRoot Binary
The file `proot-static-aarch64` is required for the Terminal feature.
It should be automatically downloaded by the Gradle build process.

If it is missing, you can manually download it from:
https://github.com/proot-me/proot-static/releases/download/v5.3.0/proot-static-aarch64

And place it in this folder (`app/src/main/assets/`).

**Note:** Ensure the filename matches exactly `proot-static-aarch64`.
