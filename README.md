# INDRA IPTV App

A modern Android IPTV and movie streaming application with watch history tracking.

## Features

### Latest Version (v1.5.260608)
✅ **Watch History Tracking** - Track all movies you watch
✅ **Movie Hub** - Browse trending, popular, top-rated, and upcoming movies
✅ **TV Shows Support** - Stream TV shows with season/episode selection
✅ **IPTV Channels** - Access live TV channels by categories, countries, regions, and languages
✅ **Multiple Streaming Servers** - vidsrc.to, 2embed.cc, embed.su, and more
✅ **Picture-in-Picture Mode** - Continue watching while doing other tasks
✅ **No Intro Video** - Launches directly to the app
✅ **Dark Mode Support** - Eye-friendly dark theme
✅ **Web Viewer** - Access web content directly in the app

## Installation

Download the latest APK and install on your Android device (Android 8.0+).


## Troubleshooting

**Video not playing?**
- Try a different streaming server
- Check your internet connection
- Make sure you have sufficient bandwidth

**App crashes?**
- Restart the application
- Clear app cache in device settings
- Reinstall the application

## Technical Details

- **Framework**: Jetpack Compose
- **Language**: Kotlin
- **Min SDK**: API 26 (Android 8.0)
- **Target SDK**: Latest Android
- **Architecture**: MVVM with Kotlin Coroutines
